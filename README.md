# Tiles Gallery

Tiles Gallery is a modern, responsive web application designed for exploring and discovering premium tile designs for various spaces. Whether you're looking for inspiration for your home or a professional project, Tiles Gallery provides a curated collection of high-quality tile options with a seamless user experience.

**Live URL:** [Click Here](https://tiles-gallery-8.vercel.app)

## Purpose

The primary goal of Tiles Gallery is to bridge the gap between tile designers and users. It provides an interactive platform where users can browse, search, and view detailed information about various tile products, helping them make informed decisions for their interior design needs.

## Key Features

- **Comprehensive Tile Gallery:** A dedicated page to explore a wide range of premium tile designs.
- **Search & Filter:** Easily find specific tiles using the built-in search functionality.
- **Detailed Product Pages:** View high-resolution images and detailed specifications for each tile.
- **User Authentication:** Secure user accounts with sign-up, sign-in, and profile management powered by Better Auth.
- **Responsive Design:** A mobile-first approach ensuring a beautiful experience across all devices (mobile, tablet, desktop).
- **Interactive UI:** Smooth animations and interactive elements like marquees and featured carousels.
- **Dynamic Data:** Content is dynamically fetched and rendered, ensuring up-to-date information.

## Tech Stack & Packages

The project is built using **Next.js 16** and leverages several modern libraries and tools:

### Core
- **Next.js:** React framework for server-side rendering and static site generation.
- **React:** For building user interfaces.
- **MongoDB:** Database for storing user and application data.

### UI & Styling
- **Tailwind CSS:** For utility-first styling.
- **@heroui/react:** A high-quality React UI component library.
- **Lucide React & React Icons:** Extensive icon sets for a modern look.
- **Swiper:** For building high-performance touch sliders and carousels.
- **React Fast Marquee:** For creating smooth scrolling text and image marquees.
- **React Toastify:** For elegant and non-intrusive notifications.

### Authentication
- **Better Auth:** A robust and flexible authentication solution for Next.js.

### Development Tools
- **ESLint:** For maintaining code quality and consistency.
- **PostCSS:** For transforming CSS with JavaScript.

## Getting Started

To run the project locally:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/samiul-hasan-tanzim/tiles-gallery-8.git
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Set up environment variables:**
    Create a `.env` file in the root directory and add your MongoDB and Auth credentials.
4.  **Run the development server:**
    ```bash
    npm run dev
    ```
5.  **Open the app:**
    Navigate to `http://localhost:3000` in your browser.
